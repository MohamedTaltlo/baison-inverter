# BAISON Service Manager الإصدار 4.0.0

- تم حذف قراءة الساعة وضبطها ومزامنتها (QT / DAT) من التطبيق لأنها غير مثبتة على جهاز BAISON المختبر.
- زر «حفظ الصيانة» يبقى غير مفعّل حتى إدخال: الهوية الحقيقية للجهاز، اسم الزبون، تاريخ ووقت صحيحين، نوع العطل، والفريق المسؤول. الهاتف والملاحظات اختياريان.
- عند حدوث أي خطأ من قاعدة البيانات يبقى النموذج مفتوحاً وبداخله كل ما كتبه الفني، ثم يستطيع إعادة المحاولة.
- زادت قابلية قراءة القيم ضمن لوحة المراقبة، مع خط كبير وغامق. اتّجاه التذييل إنجليزي، والاسم ورقم واتساب لا يظهران إلا عند تمرير المؤشر فوق MT_RADIUS.
- تنظيف محلي لسجلات الأحداث والقراءات (14 و3 أيام افتراضياً) مع الحفاظ على الزبائن والصيانة والتدقيق.
- الإصدار يحتوي على أداة قراءة USB HID وتحكم موثق تحقّقه قراءة لاحقة، لكنه **لا يتيح كتابة بيانات صيانة مخصصة إلى EEPROM**.
- يتوفر EXE مستقل ضمن صفحة GitHub Releases بعد نجاح اختبار Windows.
